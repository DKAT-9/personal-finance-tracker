# Personal Finance Tracker

A lightweight Flask web app to record, categorize, and analyze income and expenses with a local SQLite database.

## Features
- Add and view transactions (income/expense)
- Auto-calculated balance and totals
- Simple, clean HTML dashboard
- Secure environment variable handling with `dotenv`

## Tech Stack
Python · Flask · SQLite · HTML/CSS · Dotenv
